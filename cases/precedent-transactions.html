Selected transaction reference

Four profitable completed transactions support a 25.90x median EV/EBITDA and a $43.54 implied share price for the illustrative target. Missing equity values display as not meaningful instead of false zero P/E multiples.

The selected EV/EBITDA range is 14.68x to 37.04x. Exact unaffected-price dates were not recorded, so the reference premium table is excluded from the conclusion.
