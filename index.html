How I work

Build the model so another analyst can question it.

I keep sourced inputs, assumptions, calculations and judgment separate. The conclusion should also say what the numbers cannot establish.

01

Start with the decision

Define the investment, credit or transaction question before building schedules.

02

Separate facts from assumptions

Trace public-source inputs and keep operating, valuation and financing judgments visible.

03

Test the downside

Focus the sensitivity work on the variables that can break the case.

04

State the recommendation plainly

A pass is a valid answer. The spreadsheet does not have to manufacture a deal.
