How I work

A model is useful only when someone can challenge it.

My preference is a transparent model with visible assumptions, simple formulas, explicit checks and a conclusion that acknowledges what the numbers cannot prove.

01

Start with the decision

Define the investment, credit or transaction question before building schedules.

02

Separate facts from assumptions

Trace public-source inputs and keep operating, valuation and financing judgments visible.

03

Make the downside do real work

Test the variables that can break the case rather than adding decorative scenarios.

04

State the recommendation plainly

A pass is a valid answer. The spreadsheet does not have to manufacture a deal.
